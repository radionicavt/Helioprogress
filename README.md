# Helioprogress — sajt

Statički sajt (bez build koraka). Početna je `index.html`.

## Objava na GitHub Pages
1. Napravite repozitorijum i otpremite **sadržaj** foldera `sajt/` u koren (index.html mora biti u korenu).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Za sopstveni domen: Settings → Pages → Custom domain, pa dodajte fajl `CNAME` sa domenom.

## Pre objave
- Zamenite `https://www.helioprogress.com` sa pravim domenom u: index.html (canonical, og:url, og:image, JSON-LD), robots.txt, sitemap.xml.
- Posle objave prijavite sajt na Google Search Console i Google Business Profile.
- Ne otpremajte folder sa programom za zakazivanje — pacijentski podaci ne idu na mrežu.
